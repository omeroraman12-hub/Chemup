# ChemUp — Chemistry Upbound
Dark editorial multi-page site: 3D image spiral hero (Three.js + GLSL), Lenis, GSAP reveals.
`npm install` · `npm run dev` · `npm run build`
Pages: index (home), courses, course (`?c=id`), mini-lectures, resources. Content: `src/data.js`. Logo: `public/logo.jpeg`. PDFs: `public/resources/`. Spiral images: `public/images/img1–10.jpg`. Spiral tuning: `CONFIG` in `src/script.js`.
